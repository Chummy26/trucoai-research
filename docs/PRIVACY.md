# Dados e privacidade

Esta distribuição não contém capturas reais de partidas, screenshots de participantes, apelidos, IDs de sala/usuário, perfis de navegador, cookies, credenciais, logs de sessões nem estatísticas individuais do site. Os dados de confirmação publicados são de bots em simulação local.

As fixtures históricas de partidas reais também foram excluídas, mesmo sendo descritas como anonimizadas: anonimização técnica não documenta consentimento ou autorização para distribuição pública. Os testes de replay dessas fixtures não fazem parte desta entrega. Relatos históricos em REGRAS.md são preservados como relatos sem disponibilizar os registros dos participantes.

Antes de uma coleta com participantes, documente finalidade, consentimento, retenção, exclusão, dados mínimos e acesso. Esta publicação não inicia coleta nem conecta ao site. Nunca anexe tokens, cookies, capturas brutas ou identificadores pessoais em issues públicas.
